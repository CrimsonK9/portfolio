Orbital — building TSB’s design system

TSB had four squads, three component libraries and a Sketch file nobody quite trusted. Orbital is what replaced them: one system, adopted by every squad, documented well enough that people stopped asking me questions.

ClientTSB Bank
RoleDesign system manager
Team4 designers
Duration2021–2024
Read7 minutes

What Orbital moved

100%adoption across every squad shipping into the app
~95%component utilisation, so the system is the right size and not merely installed
350+designers, engineers and POs working from Orbital
The reframe that got it funded

I stopped pitching “let’s make a component library” and started pitching “let’s stop paying for the same decision four times”. That is the version that got funded — because it was a delivery argument, not an aesthetic one.
